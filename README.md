# Pre-Launch-Preparatory-Content
 Pre-Program Preparatory learning experience, you will be learning some basics of data science through two modules - "Analytics Problem Solving" and "Data Analysis in Excel"

 Why these topics/modules?
The aim of the pre-launch learning experience is to familiarize you with some fundamental terms and thought processes in the data industry. Although the modules on Analytics Problem Solving and Excel are optional, we highly recommend you go through them as they will help you understand the world of data in a structured manner.
The Python content is mandatory and we have given you early access so that you can start going through its content before the program starts and get a headstart (but don't worry, as you will get 2 weeks in the main program to finish the module).
